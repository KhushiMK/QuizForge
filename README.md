# 🚀 QuizForge - Online Quiz Maker & Test Platform

QuizForge is a full-stack web application that allows users to create, manage, and attempt quizzes. It provides a seamless experience for both quiz creators and participants.

---

## 🔥 Features

* 🔐 User Authentication (Login/Register)
* 🧠 Create and Manage Quizzes
* ➕ Add Multiple Questions with Options
* 🎯 Attempt Quizzes
* 📊 Score Calculation and Result Display
* 🎨 Clean UI with Modern Dark Theme

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS
* **Backend:** Flask (Python)
* **Database:** MySQL
